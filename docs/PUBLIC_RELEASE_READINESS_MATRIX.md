### VS Code Marketplace Submission

The following must ALL be PASS before Marketplace submission:

- [ ] LICENSE file present and consistent across workspace
- [ ] VSIX audit passes in `--mode public-release` (no .map, no src, no secrets)
- [ ] VS Code extension build clean

### Production Billing Deployment

The following must ALL be PASS before billing goes to production:

- [ ] Staging environment configured and running
- [ ] All staging billing reconciliation steps complete (see `PRODUCTION_BILLING_RECONCILIATION_PLAN.md`)

- [ ] Staging reconciler idempotency verified
- [ ] Audit log in `PRODUCTION_BILLING_RECONCILIATION_PLAN.md` filled in
