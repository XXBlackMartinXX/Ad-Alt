# Code of Conduct

PromptProfit is committed to providing a respectful, professional, and harassment-free experience for everyone who participates in this project — contributors, maintainers, and anyone interacting through issues, pull requests, discussions, or any other project space.

## Expected Behavior

- Communicate respectfully and assume good faith.
- Be constructive in disagreements; critique ideas, not people.
- Respect differing viewpoints, experience levels, and backgrounds.

## Unacceptable Behavior

Harassment, abuse, discriminatory remarks, personal attacks, and any conduct that makes the project space unsafe or unwelcoming are not allowed. Maintainers may remove comments, close issues/PRs, or restrict participation for violations of this policy.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please report it privately to **security@promptprofit.dev** rather than responding in public. Reports will be handled confidentially and reviewed by a maintainer.

## Scope

This Code of Conduct applies to all project spaces (GitHub issues, pull requests, discussions, code review) and to any other setting where someone is representing the project.
